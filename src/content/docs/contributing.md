NOALBS Cloud is open source under the AGPL-3.0. Bug reports, fixes, new stream server kinds and
translations are welcome.

## The code

The code is at [github.com/NOALBS/noalbs-cloud](https://github.com/NOALBS/noalbs-cloud): a Rust
backend and a React dashboard. Its
[README](https://github.com/NOALBS/noalbs-cloud#readme) gets it running on your machine, with
fakes for Twitch, Kick, YouTube, BELABOX Cloud and Moblin so you don't need accounts or devices,
and [CONTRIBUTING.md](https://github.com/NOALBS/noalbs-cloud/blob/main/CONTRIBUTING.md) has the
checks and rules for pull requests.

For anything bigger than a fix, open an issue or ask on
[Discord](https://discord.gg/efWu5HWM2u) first.

Found a security problem? Please follow
[SECURITY.md](https://github.com/NOALBS/noalbs-cloud/blob/main/SECURITY.md) instead of opening an
issue.

## These docs

These pages are at [github.com/NOALBS/noalbs-cloud-docs](https://github.com/NOALBS/noalbs-cloud-docs).
Every page has an **Edit page** link at the bottom. To run the site locally:

```sh
pnpm install
pnpm dev
```
